# 2D 웹게임 프로젝트

Phaser와 Next.js를 사용한 2D 웹게임입니다.

## 설치 및 실행

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## 기능

### 로그인 화면 (`/login`)
- 아이디/비밀번호 입력 폼
- 로그인 버튼 클릭 시 게임 화면으로 이동 (현재는 인증 없이 바로 통과)

### 게임 화면 (`/game`)
- Phaser 기반 2D 게임
- 초록색 캐릭터 (플레이어)
- WASD 또는 방향키로 이동
- 카메라가 플레이어를 따라다님
- 50x50 타일 맵

## 조작법

- **W / ↑** : 위로 이동
- **S / ↓** : 아래로 이동
- **A / ←** : 왼쪽으로 이동
- **D / →** : 오른쪽으로 이동

## 프로젝트 구조

```
app/
├── login/
│   └── page.tsx          # 로그인 화면
├── game/
│   └── page.tsx          # 게임 메인 화면 (Phaser)
├── page.tsx              # 메인 페이지 (로그인으로 리다이렉트)
├── layout.tsx
└── globals.css

types/
└── phaser.d.ts           # Phaser 타입 정의
```

## 기술 스택

- **Next.js 16** - React 프레임워크
- **Phaser 3** - 2D 게임 엔진
- **TypeScript** - 타입 안정성
- **Tailwind CSS** - 스타일링
